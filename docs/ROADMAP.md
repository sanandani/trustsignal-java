# Roadmap

The project website will be published at **https://sanandani.github.io/trustsignal-java/** after its first successful deployment.

- Add a versioned JSON claim codec and serialization round-trip contract.
- Consider ES256 and status-list revocation adapters behind the existing ports.
- Expand synthetic examples and JMH reporting.
- Evaluate publication readiness, namespace verification, and signing setup.

Items are proposals, not commitments. The framework remains conceptual and not empirically validated.
