# Contributor Covenant Code of Conduct

We pledge to make participation in this project welcoming and respectful to everyone. Harassment, discrimination, personal attacks, and disclosure of private information are not acceptable.

Project maintainers are responsible for clarifying standards and taking fair, proportionate corrective action. Report unacceptable behavior through the private reporting route described in [SECURITY.md](SECURITY.md).

This code applies in project spaces and when someone represents the project publicly.
