Verified signals contribute at full configured weight. Unverifiable signals leave values unchanged and reduce confidence.

How to read this

01

Value

A weighted summary of the sample evidence that is verified or inferred for that dimension.

02

Confidence

How much of the configured evidence weight has a usable verification state.

03

Explanation

See which synthetic signals contribute, remain unknown, or are excluded as invalid.

Use it in Java

Build on the same model.

Compose injected verification capabilities, score each ACE-U dimension, and keep the result interpretable.

var result = scorer.score(evidence);
result.profile().dimensions()
    .forEach((dimension, score) ->
        System.out.println(dimension + ": " + score.value()));
!
