TrustSignal Java

A reference library for verifying professional identity claims and representing trust across Authenticity, Credibility, Empathy, and Uniqueness.

Conceptual framework; not empirically validated. ACE-U values are not a measure of a person's worth or overall trustworthiness.

Install

git clone https://github.com/sanandani/trustsignal-java.git
cd trustsignal-java
./gradlew build

Quick start

Construct an AceUScorer with four dimension weights, then pass evidence with an explicit verification outcome. The result preserves separate values and confidence for every dimension.

var result = scorer.score(List.of(evidence));
result.profile().dimensions().forEach((dimension, score) ->
    System.out.println(dimension + ": " + score.value()));
